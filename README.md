# 🐍 Snake

Ein klassisches Snake-Spiel für den Browser – reines HTML, CSS und JavaScript, keine Abhängigkeiten.

## Spielen

`index.html` im Browser öffnen – oder über GitHub Pages spielen.

## Steuerung

| Aktion | Taste |
|---|---|
| Bewegen | Pfeiltasten oder WASD |
| Start / Pause | Leertaste |
| Mobil | Wischen oder Bildschirm-Buttons |

## Features

- Wird mit jedem gefressenen Apfel schneller
- Highscore wird im Browser gespeichert
- Funktioniert auf Desktop und Smartphone
