# Bilder

Die Bilder in diesem Ordner sind eigene Illustrationen im Stil persischer Miniaturmalerei
(SVG, frei verwendbar für dieses Projekt):

| Datei | Motiv |
|---|---|
| `bamiyan.svg` | Tal von Bamiyan mit der leeren Nische des großen Buddhas |
| `dambura-nawaz.svg` | Hazara-Musiker mit Dambura, Chapan und besticktem Käppchen |
| `madar.svg` | Hazara-Frau in traditionellem Kleid mit Yakhan-Stickerei |
| `band-e-amir.svg` | Die türkisfarbenen Seen von Band-e Amir |
| `qishlaq.svg` | Dorf (Qishlaq) im Hazaradschat |
| `chopan.svg` | Hirte mit Herde im Abendlicht |

## Eigene Fotos hinzufügen

1. Foto (z. B. `familie.jpg`) in diesen Ordner legen.
2. In `js/poems.js` in der Liste `GALLERY` einen Eintrag ergänzen:
   ```js
   { src: "Bilder/familie.jpg", caption: "توضیحِ عکس" },
   ```

Bitte nur Fotos verwenden, an denen ihr die Rechte habt oder die frei lizenziert sind
(z. B. Wikimedia Commons, mit Quellenangabe).
